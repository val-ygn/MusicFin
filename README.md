# MusicFin

NB : The app is currently under development, and no code will be uploaded to this repo, it's in another repo.
This repo stocks the apk, when it'll be available, and the website in "website" branch.

MusicFin is the first open source Jellyfin app for WearOS, with an Android App that allows you listen to your music (using your Jellyfin Server ofc) and to send the credentials to your watch app, for a simplified connection.
(Since it's in development, the whole presentation of the project isn't there, but when the app will be available, it'll be there)

So, to install this app on your watch, you need at least WearOS 3.0, but the recommended version tho is WearOS 5 or more.
And, to install the app on your phone, you'll need Android 8.0, but it'll work better with Android 15.
